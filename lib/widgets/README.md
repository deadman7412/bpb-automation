# Widgets Directory

This directory contains reusable UI components used across multiple screens.

## Purpose

Widgets are self-contained UI components that can be reused throughout the app.

## Widgets

### ScanButton
Primary action button for initiating scans.

### IpListTile
List item displaying IP address with test stats.

### LogEntry
Individual log entry display with color coding.

### CredentialForm
Form for entering Cloudflare credentials.

## Guidelines

- Widgets should be as reusable as possible
- Accept data through constructor parameters
- Use callbacks for user interactions
- Keep widgets focused on presentation
- Document widget parameters
- Follow Material Design component patterns
- NO EMOJIS in any UI text
